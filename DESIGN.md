# Design System

## Brand

Review Top Lawyers should feel like a premium legal directory rather than a traditional law firm website.

Primary visual direction:

- Deep navy
- Warm neutral/off-white
- White
- Restrained gold accent
- Muted gray text

The exact Tailwind values should be selected during implementation and centralized rather than scattered throughout components.

---

## Typography

Use a professional modern type system.

Headings should have strong hierarchy.

Body text should prioritize readability.

Avoid excessively decorative fonts.

---

## Layout

Use a consistent centered content container.

Recommended maximum width:

- approximately 1200–1280px

Use generous whitespace.

Sections should have clear visual separation.

---

## Cards

Lawyer cards should feel premium and informative.

Typical information:

- Photo
- Name
- Practice area
- Location
- Rating
- Review count
- Short description
- Profile CTA

Do not overload cards with information.

---

## Buttons

Primary CTA:

- Strong contrast
- Clear label
- Moderate radius
- Subtle hover animation

Secondary CTA:

- Less visual weight
- Still clearly interactive

---

## Forms

Inputs should be:

- Clearly labeled
- Comfortable on mobile
- Accessible
- Visually consistent
- Easy to scan

Focus states must be obvious.

---

## Animation

Use Framer Motion.

Recommended:

- Fade/slide entrance
- Staggered card appearance
- Subtle hover movement
- Button interaction
- Mobile menu transitions
- Section reveal

Avoid:

- Constant motion
- Large parallax effects
- Excessive bouncing
- Long animations

Respect prefers-reduced-motion where practical.

---

## Responsive

Design for:

- Large desktop
- Desktop
- Tablet
- Mobile
- Small mobile

Never depend on hover for essential information.

Navigation must become a mobile-friendly menu.

Grids should collapse naturally.

Forms should become single-column on small screens.
